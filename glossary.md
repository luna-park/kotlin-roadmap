# Глоссарий

Служебные слова, символы и термины, которые встречаются в этих документах. Не учебник
и не полная справка по языку — только то, что реально используется по маршруту, с
пояснением в одну-две строки.

Читать подряд не нужно. Это страница, куда возвращаются, встретив незнакомое слово.

[Обзор маршрута](README.md)

## Ключевые слова языка

### Объявления

| Слово | Что означает |
|---|---|
| `val` | неизменяемая ссылка, аналог `final` в Java. По умолчанию используют именно её |
| `var` | изменяемая ссылка |
| `fun` | функция. Может лежать прямо в файле, без класса |
| `class` | класс. **По умолчанию `final`** — унаследоваться нельзя без `open` |
| `interface` | интерфейс; может содержать реализации методов по умолчанию |
| `object` | синглтон: объявление класса и создание единственного экземпляра сразу |
| `companion object` | «статические» члены класса. В Kotlin нет `static`, вместо него это |
| `typealias` | второе имя для существующего типа, для сокращения длинных дженериков |
| `package` / `import` | как в Java; `package` не обязан совпадать с путём к файлу |
| `const` | константа, вычисляемая при компиляции. Только для примитивов и `String` |

### Модификаторы классов

| Слово | Что означает |
|---|---|
| `data class` | класс-хранилище данных: `equals`, `hashCode`, `toString`, `copy` генерируются автоматически |
| `data object` | то же для `object`: добавляет осмысленный `toString`. Требует Kotlin 1.9+ |
| `sealed class` / `sealed interface` | ограниченная иерархия: компилятор знает **всех** наследников, поэтому проверяет, что `when` обработал все варианты |
| `enum class` | фиксированный набор **экземпляров** (в отличие от `sealed` — фиксированного набора **типов**) |
| `open` | разрешить наследование класса или переопределение метода |
| `override` | переопределение. В Kotlin это **обязательное ключевое слово**, а не аннотация |
| `abstract` | без реализации, требует переопределения |
| `inner class` | вложенный класс с доступом к внешнему. Без `inner` вложенный класс статический |

### Видимость

| Слово | Кто видит |
|---|---|
| `public` | все. Значение **по умолчанию** (в Java по умолчанию package-private) |
| `private` | только внутри класса, или только внутри файла — для объявлений верхнего уровня |
| `protected` | класс и наследники |
| `internal` | всё внутри модуля (единицы компиляции Gradle). Прямого аналога в Java нет |

### Инициализация

| Слово | Что означает |
|---|---|
| `init { }` | блок, выполняемый при создании объекта; аналог кода в конструкторе |
| `constructor` | дополнительный конструктор. Нужен редко: обычно хватает значений по умолчанию |
| `lateinit var` | «проинициализирую позже, но точно до первого чтения». Только для не-null ссылочных типов |
| `by lazy { }` | вычислить значение при первом обращении и запомнить. Потокобезопасно по умолчанию |

### Управление потоком выполнения

| Слово | Что означает |
|---|---|
| `when` | замена `switch`, но мощнее: работает как выражение, проверяет типы, диапазоны, произвольные условия |
| `is` | проверка типа, аналог `instanceof`. После проверки тип **приводится автоматически** (smart cast) |
| `as` / `as?` | приведение типа; `as?` возвращает `null` вместо исключения |
| `in` | «входит в» — для диапазонов и коллекций: `if (x in 1..10)` |
| `return@label` | возврат из конкретной лямбды, а не из внешней функции |
| `throw` / `try` / `catch` / `finally` | как в Java. Разница: **все исключения непроверяемые**, `throws` в сигнатуре нет |

Особенность: `if`, `when` и `try` — **выражения**, то есть возвращают значение:

```kotlin
val max = if (a > b) a else b      // тернарного оператора ?: в Kotlin нет
val n = try { s.toInt() } catch (e: Exception) { 0 }
```

## Символы и операторы

### Null safety

| Символ | Что означает |
|---|---|
| `String` | тип, который **не может** быть `null`. Присвоить `null` не даст компилятор |
| `String?` | тип, который может быть `null`. Это **другой тип**, не то же самое, что `String` |
| `?.` | safe call: вызвать, если не `null`, иначе вернуть `null`. `user?.name?.length` |
| `?:` | elvis-оператор: значение слева, а если оно `null` — то справа. `name ?: "без имени"` |
| `!!` | «я гарантирую, что не null». Бросает `NullPointerException`, если ошибся. **Почти всегда признак, что код стоит переписать** |
| `String!` | *platform type*: пришло из Java без аннотаций, nullability неизвестна. Единственная дыра в системе |

### Прочие символы

| Символ | Что означает |
|---|---|
| `->` | в лямбде разделяет параметры и тело; в `when` — условие и результат |
| `it` | неявное имя единственного параметра лямбды. `list.map { it * 2 }` |
| `this` | текущий объект. В лямбдах с получателем — объект, к которому «прикреплена» лямбда |
| `::` | ссылка на функцию или свойство: `list.map(::transform)`, `model::onClick` |
| `..` | диапазон включительно: `1..10` |
| `until` | диапазон без последнего: `0 until list.size` |
| `downTo` / `step` | обратный отсчёт / шаг: `10 downTo 1 step 2` |
| `$` / `${}` | подстановка в строку: `"Привет, $name"`, `"Всего: ${list.size}"` |
| `"""..."""` | многострочная строка без экранирования; обычно с `.trimIndent()` |
| `_` | не синтаксис, а **соглашение**: `_state` — приватное изменяемое поле, у которого есть публичный неизменяемый двойник `state` |
| `*` | spread-оператор: передать массив в `vararg`-параметр |
| `field` | внутри сеттера — ссылка на само хранилище свойства. Написать в сеттере имя свойства вместо `field` = бесконечная рекурсия |
| `@Аннотация` | аннотация, как в Java: `@Serializable`, `@Composable`, `@Preview` |
| `@OptIn(...)` | согласие использовать API, помеченный как экспериментальный |
| `<out T>` / `<in T>` | вариантность дженерика: `out` — тип только возвращается, `in` — только принимается |

## Функции: приёмы, которые нужно узнавать

**Expression body** — тело из одного выражения, `return` и тип не пишутся:

```kotlin
fun double(x: Int) = x * 2
```

**Значения по умолчанию и именованные аргументы** — заменяют перегрузки:

```kotlin
fun connect(host: String, port: Int = 8080, retry: Boolean = false)

connect("example.com", retry = true)     // порядок не важен, читается однозначно
```

**Extension function** (функция-расширение) — выглядит как метод чужого класса, но
им не является:

```kotlin
fun String.isValidEmail(): Boolean = contains("@")

"test@mail.ru".isValidEmail()
```

Разрешается статически, по объявленному типу; доступа к `private`-членам не имеет.
Почти вся стандартная библиотека коллекций — это extensions.

**Лямбда с получателем** (`A.() -> Unit`) — внутри блока `this` равен объекту `A`,
поэтому его члены доступны без префикса. На этом построены `apply { }`, `flow { }`,
`Modifier`-цепочки и вся разметка Compose:

```kotlin
val client = HttpClient().apply {
    timeout = 5_000      // это this.timeout
}
```

**Trailing lambda** — если лямбда последний аргумент, её выносят за круглые скобки.
Именно поэтому Compose-код выглядит как разметка, а не как вызовы функций:

```kotlin
Column(modifier = Modifier.padding(8.dp)) {   // лямбда — второй аргумент Column
    Text("Привет")
}
```

**Scope-функции** — пять похожих функций для работы с объектом:

| Функция | Объект внутри | Возвращает | Типичное применение |
|---|---|---|---|
| `let` | `it` | результат блока | null-безопасное преобразование |
| `apply` | `this` | сам объект | настройка при создании |
| `also` | `it` | сам объект | логирование в цепочке |
| `run` | `this` | результат блока | блок вычислений |
| `with` | `this` | результат блока | много обращений к одному объекту |

## Корутины

| Термин | Что означает |
|---|---|
| **корутина** | «легковесный поток»: код, который умеет приостанавливаться и возобновляться. Её состояние живёт в куче, а не в стеке ОС, поэтому их можно тысячи на один поток |
| `suspend` | модификатор функции: «умею приостанавливаться». Вызвать можно только из другой `suspend`-функции или из корутины |
| **приостановка** (suspend) | корутина запоминает, где остановилась, и **отпускает поток**. Через время продолжает с того же места |
| `delay(ms)` | приостановка на время. **Не** `Thread.sleep`: поток остаётся свободным |
| `CoroutineScope` | область: владеет корутинами и умеет их всех отменить одной командой |
| **структурная конкурентность** | принцип «корутина всегда принадлежит области»: смерть области = отмена всех детей. Именно это снимает задачу «не забыть отписаться» |
| `Job` | хэндл корутины: `cancel()`, `join()`, `isActive` |
| `SupervisorJob` | вариант `Job`, при котором падение одного ребёнка не убивает остальных |
| `launch` | запустить корутину, результат не нужен. Возвращает `Job` |
| `async` / `await` | запустить корутину с результатом. Возвращает `Deferred<T>`, значение забирают через `await()` |
| `coroutineScope { }` | `suspend`-функция: создать вложенную область и дождаться всех детей |
| `supervisorScope { }` | то же, но с изоляцией падений |
| `withContext(ctx) { }` | выполнить блок в другом контексте (обычно — на другом диспетчере) и вернуть результат |
| `runBlocking { }` | заблокировать текущий поток до конца корутины. **Только в `main()` и в тестах** |
| `Dispatchers` | распределители по потокам: `Default` (вычисления), `IO` (сеть и диск), `Main` (UI) |
| `CancellationException` | исключение, которым реализована отмена. Ловить широким `catch (e: Exception)` и глотать — ошибка, надо пробрасывать |
| `ensureActive()` / `yield()` | сделать цикл без suspend-вызовов отменяемым |
| `withTimeout(ms)` | ограничить время; `withTimeoutOrNull` вместо исключения вернёт `null` |
| `viewModelScope` | готовая область внутри `ViewModel` (Android), отменяется в `onCleared()` |
| `lifecycleScope` | готовая область `Activity` / `Fragment`, отменяется при их уничтожении |

## Flow

| Термин | Что означает |
|---|---|
| `Flow<T>` | асинхронный поток значений: много значений во времени. Аналог `Stream`, но не блокирующий |
| **холодный** (cold) | тело не выполняется, пока никто не подписался; каждая подписка — новый запуск с нуля |
| **горячий** (hot) | существует независимо от подписчиков (`StateFlow`, `SharedFlow`) |
| `flow { }` | функция-строитель: сохраняет лямбду, из которой потом будут эмититься значения |
| `emit(value)` | отдать значение вниз по цепочке. Доступна внутри `flow { }` без объявления |
| `collect { }` | терминальная операция: запускает цепочку. `suspend`-функция |
| `launchIn(scope)` | альтернатива `collect`: подписаться, создав корутину в области, и не блокировать текущую |
| **оператор** | функция, превращающая один `Flow` в другой (`map`, `filter`, …). Ничего не выполняет до `collect` |
| **upstream** | всё, что **выше** по цепочке — ближе к производителю |
| **downstream** | всё, что **ниже** по цепочке — ближе к `collect` |
| **backpressure** | обратное давление: медленный потребитель тормозит быстрого производителя. В Flow получается само, потому что `emit` приостанавливается |
| `flowOn(ctx)` | задать контекст для **upstream**. Аналога `observeOn` нет: downstream работает там, где вызван `collect` |
| `catch { }` | перехватить ошибку **выше** по цепочке. Ошибку внутри `collect { }` не поймает |
| `debounce(ms)` | пропустить значение только если после него была пауза. Для поиска по вводу |
| `distinctUntilChanged` | не пропускать значение, равное предыдущему |
| `flatMapLatest` | при новом значении отменить обработку предыдущего |
| `combine` / `zip` | собрать несколько потоков: по последним значениям / строго парами |
| `StateFlow` | горячий поток-состояние: значение есть всегда, дубликаты отсекаются, новый подписчик сразу получает текущее. Замена `LiveData` |
| `SharedFlow` | горячий поток-события: начального значения нет, поэтому событие не повторится при новой подписке |
| `MutableStateFlow` | версия `StateFlow`, которую можно менять. Держат приватной, наружу отдают через `asStateFlow()` |
| `update { }` | атомарно прочитать текущее значение и записать новое |
| `stateIn` / `shareIn` | превратить холодный поток в горячий: один запуск на всех подписчиков |
| `SharingStarted.WhileSubscribed(ms)` | политика для `stateIn`: работать, пока есть подписчики, плюс запас времени на переподписку |

## Compose

| Термин | Что означает |
|---|---|
| `@Composable` | функция, описывающая часть UI. Возвращает `Unit`, а не объект View |
| **рекомпозиция** | повторный вызов `@Composable`-функций при изменении состояния. Может произойти многократно и в любом порядке — поэтому внутри нельзя делать побочные действия |
| `remember { }` | сохранить значение между рекомпозициями |
| `mutableStateOf(x)` | наблюдаемое значение: Compose отслеживает, кто его читает, и перерисовывает только их |
| `rememberSaveable` | как `remember`, но переживает пересоздание `Activity` (Android) |
| `by` (с состоянием) | делегат, чтобы писать `count` вместо `count.value`. Требует импортов `getValue` и `setValue` |
| **state hoisting** | «поднятие состояния»: компонент принимает значение и колбэк, а состояние живёт выше. Без этого код разваливается |
| `Modifier` | цепочка настроек компонента: отступы, размеры, обработка нажатий. **Порядок важен** |
| `dp` / `sp` | единицы: `dp` для размеров, `sp` для шрифтов (учитывает системный масштаб текста) |
| `LazyColumn` | список, рендерящий только видимые элементы. Замена `RecyclerView` со всей его обвязкой |
| `key` (в `items`) | стабильный идентификатор элемента списка; без него будут артефакты при вставке и удалении |
| `LaunchedEffect(keys)` | запустить `suspend`-код при появлении компонента; перезапустить при изменении ключа |
| `DisposableEffect` | то же, но с блоком `onDispose` для очистки при уходе |
| `rememberCoroutineScope()` | область для запуска корутин из колбэков вроде `onClick` |
| `collectAsState()` | подписаться на `StateFlow` из `@Composable` |
| `collectAsStateWithLifecycle()` | то же плюс остановка подписки, когда экран в фоне (Android) |
| `Scaffold` | каркас экрана: верхняя панель, кнопка, место для сообщений |
| `@Preview` | просмотр компонента в IDE без запуска приложения. Работает только для stateless-компонентов |

## Android

| Термин | Что означает |
|---|---|
| `Activity` | точка входа из системы и владелец окна. В современном приложении обычно **одна на всё приложение** |
| `ComponentActivity` | базовый класс для Compose-приложений (`AppCompatActivity` нужен только для XML) |
| `Application` | объект уровня приложения, живёт всё время работы. Обычно нужен только чтобы держать контейнер зависимостей |
| `ViewModel` | класс, хранящий состояние экрана. **Переживает поворот экрана**, потому что хранится отдельно от `Activity` |
| `onCleared()` | вызывается при окончательном уничтожении `ViewModel`; здесь отменяется `viewModelScope` |
| `SavedStateHandle` | хранилище, переживающее даже убийство процесса системой |
| **жизненный цикл** | `onCreate` → `onStart` → `onResume` → `onPause` → `onStop` → `onDestroy`. Поворот экрана = уничтожение и создание заново |
| `AndroidManifest.xml` | описание приложения для системы: компоненты, разрешения, иконка |
| `minSdk` | минимальная версия Android, на которой приложение запустится |
| `compileSdk` | версия API, против которой идёт компиляция. Обычно последняя |
| `targetSdk` | «протестировано на этой версии». Система включает все поведенческие изменения до неё включительно — поэтому подъём `targetSdk` может сломать работающее приложение |
| **runtime permission** | разрешение, которое нужно спрашивать в работающем приложении, а не только объявить в манифесте. `INTERNET` к таким **не** относится |
| **insets** | отступы под системные панели. При edge-to-edge их нужно учитывать, иначе контент уедет под статус-бар |
| `Logcat` | системный лог; основной инструмент отладки |
| `ANR` | Application Not Responding: главный поток заблокирован слишком долго |
| **Navigation Compose** | навигация между экранами: back stack, аргументы, работа системной кнопки «назад» |
| `Room` | библиотека для SQLite: SQL проверяется при компиляции, запросы могут возвращать `Flow` |
| `@Entity` / `@Dao` | таблица / интерфейс с запросами в Room |
| `DataStore` | замена `SharedPreferences` с `suspend`-API и чтением через `Flow` |
| **single source of truth** | «единственный источник истины»: UI подписан на БД, сеть только обновляет БД. Приложение работает офлайн |
| `Coil` | загрузка картинок по URL; в Compose — компонент `AsyncImage` |
| `Hilt` | фреймворк внедрения зависимостей. Нужен, когда ручная сборка объектов становится громоздкой |
| `R8` / ProGuard | сжатие и обфускация кода в release-сборке. Может выбросить нужное — release всегда проверяют отдельно |
| `keystore` | файл с ключом подписи APK. Пароли к нему **не хранят в git** |
| APK / AAB | пакет для установки / формат для публикации в Google Play |

## Gradle

| Термин | Что означает |
|---|---|
| `build.gradle.kts` | скрипт сборки на Kotlin DSL. Современный стандарт вместо Groovy-варианта `build.gradle` |
| `implementation` | зависимость, доступная только этому модулю |
| `api` | зависимость, «протекающая» в зависящие модули. Использовать осознанно |
| `debugImplementation` | только для debug-сборки (например, инструменты отладки) |
| `platform(...)` / BOM | «спецификация версий»: согласует версии группы артефактов, чтобы не указывать их поштучно |
| **version catalog** | файл `gradle/libs.versions.toml` с версиями всех зависимостей в одном месте |
| `plugins { }` | подключение плагинов: Android, Kotlin, сериализация, Compose |
| KSP | генератор кода на этапе компиляции; нужен, например, для Room |
| `jvmToolchain(17)` | версия JDK, которой собирается проект |
